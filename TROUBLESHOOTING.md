## Common Issues & Solutions

### 1. Python Not Found
**Problem:** Running `python main.py` gives error: *"python is not recognized as an internal or external command."*  
**Solution:**  
- Make sure Python 3.x is installed.  
- Add Python to your system PATH during installation.  
- Verify installation by running:  
  ```bash
  python --version
