# Rule-Based Chatbot 🤖

## 📖 Introduction
This project is a **simple rule-based chatbot** built in Python. It responds to predefined user inputs using basic control flow and decision-making logic. The chatbot demonstrates how beginner-level artificial intelligence concepts can be applied to create interactive systems.

## ✨ Features
- Greeting and Exit Handling  
- Decision-Making with If-Else Logic  
- Continuous Interaction Loop  
- Custom Responses  

## 🛠️ Requirements
- Python 3.x  
- No external libraries required
