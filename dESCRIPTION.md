# Project Description: Rule-Based Chatbot 🤖

## 📖 Overview
This project is a **simple rule-based chatbot** created in Python. It responds to predefined user inputs using basic control flow and decision-making logic. The chatbot demonstrates how beginner-level artificial intelligence concepts can be applied to create interactive systems.

## 🔹 Objectives
- Build a chatbot that can handle greetings and exit commands.  
- Implement decision-making using if-else logic.  
- Run the chatbot in a continuous loop for ongoing interaction.  
- Provide simple responses to common phrases like "thank you" or "how are you."  

## 🔹 Key Skills Practiced
- **Control Flow**: Using loops and conditions to manage program execution.  
- **Decision-Making Logic**: Applying if-else statements to generate responses.  
- **Basic AI Concepts**: Understanding rule-based systems as a foundation for AI.  
- **Interactive Programming**: Creating console-based applications that engage users.
